# Initial implementation integration contract

Implementation decision IMPL-DEC-001 (2026-10-28): no package slugs/namespaces are fixed by the source specs. Use theme `packages/theme/wooshop` (text domain wooshop), plugin `packages/plugin/wooshop-commerce` (text domain wooshop-commerce), PHP namespace `WooShop\Commerce`, version0.1.0-development. REST remains `commerce/v1`; Store API remains extensions.commerce. This is a reversible engineering choice, not business approval.

Root owns plugin bootstrap,Infrastructure,Support,Security,Kernel,Settings,Jobs,tools,profiles,tests/integration and shared dependencies. Theme worker owns theme files and tests/theme. Catalog worker owns src/Catalog,src/Customer,src/Merchandising,src/Seo,assets/catalog.*,views/catalog and tests/catalog. Marketplace worker owns src/Marketplace,src/Inventory,src/Finance,views/marketplace,assets/marketplace.* and tests/marketplace. Do not overwrite another owner. All agents are AI contributors, not independent human approvals.

## Shared PHP contracts (root implements)

- Infrastructure\Database($wpdb): table(string $suffix):string returns prefix+wooshop_+allowlisted suffix; transaction(callable):mixed; now():UTC MySQL time; wpdb():object. No DB transaction spans remote request.
- Infrastructure\EntityStore(Database): create(string $kind,array $data,string $owner='0',?string $id=null):array; get(string $kind,string $id):?array; find(string $kind,?string $owner=null,int $limit=20,?string $cursor=null):array; update(string $kind,string $id,int $version,array $data):array; delete(string $kind,string $id,int $version):bool. Records expose id,kind,owner_id,version,data,created_at,updated_at. find returns records list; lexical UUID cursor is last id. Transactionally persisted plugin extension records, not native order storage.
- Support\DomainError(string $errorCode,string $message,int $status=422,array $details=[]):RuntimeException exposes errorCode,status,details.
- Support\Rest::respond(callable):mixed catches DomainError into WP_Error safe response; Rest::version(WP_REST_Request):int validates quoted If-Match (428missing/412stale service error); Rest::idempotency(WP_REST_Request):string validates16..128key.
- Security\Authorization(Database): can(string $capability,?string $sellerId=null):bool; require(string $capability,?string $sellerId=null):void. Current actor from WP session; site scope comes from independent DB prefix. Platform operators use manage_woocommerce/manage_options except independent finance approvals; seller membership checked live in memberships table. No seller_id selector grants permission.
- Module entry classes Catalog\CatalogModule,Marketplace\MarketplaceModule receive (Database,EntityStore), expose register():void (hooks/routes/shortcodes) and optional capabilities():array (implemented vs blocked). Root invokes only declared classes; no invented APIs.
- Inventory/Finance/Marketplace specialized schemas are owned by their worker via static Schema::definitions(string $prefix,string $charset):array of dbDelta SQL; root installer merges them if class exists. Shared EntityStore has entities, jobs, events, operations,rate_limits tables. Marketplace worker owns seller membership/offer/pool/reservation/ledger schemas in Marketplace\Schema; root calls its definitions during migration.
- Classes autoload from src by namespace. Pure domain services may avoid WP entirely and should have executable tests. No production success doubles. Providers without approved config fail unavailable; marketplace activation remains blocked without legal/payment/maintenance gates.

All work must cite read docs/IDs in per-worker evidence JSON at docs/implementation/evidence-<task>.json including read_paths and fingerprints, changed files, commands/results and incomplete scope. Parent merges ledgers/status. Do not touch central CSV registries. Native IDs in APIs are decimal strings; money amount_minor string,currency,exponent. Use actual WP/WC APIs with installed-source or primary-doc verification. Preserve historical specs.
