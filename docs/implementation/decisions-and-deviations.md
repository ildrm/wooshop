# Implementation decisions and deviations

These are implementation interpretations, not invented business approval. Original requirement/decision/ADR IDs remain unchanged.

| ID | Decision and reason | Status and consequence |
|---|---|---|
| DEV-AUTH-001 | The current user request/master implementation prompt supersedes the earlier documentation-only restriction, including FR-G001's assignment boundary. | Authorized implementation scope. Original documentation records remain historical. No production action is authorized. |
| DEV-NAME-001 | Use theme `wooshop`, plugin `wooshop-commerce`, namespace `WooShop\Commerce`, version0.1.0 because the baseline did not fix package identifiers. | Reversible development naming; GPL-2.0-or-later. One package of each type, no store forks. |
| DEV-ENV-001 | Use exact locally verified WP7.1.3/WC11.2.1/PHP8.4.27/MariaDB10.11.19 with official digest-pinned Docker images. Host PHP8.5.8 is lint/pure-domain only. | Local test matrix only; not universal support. Sources and digests in dependency verification. |
| DEV-BROWSER-001 | CUA had no available browser; official Playwright Chromium download returned403 with a location restriction. Use the existing Google Chrome156 with a temporary headless profile for the explicitly requested E2E tests. | No bypass of the restricted download and no user browser profile access. Other browsers/assistive technologies NOT RUN. |
| DEV-DB-001 | Preserve ambient database transactions using unique savepoints and MariaDB `@@in_transaction` inspection. | Executed on MariaDB10.11.19. Other MySQL/MariaDB versions are unverified; unavailable transaction-state inspection fails503. |
| DEV-COOKIE-001 | Prefix the conceptual guest cookie with a site hash: `wooshop_guest_<sitehash>`, signed random identity, HttpOnly/SameSite and session-bound CSRF. | Prevents loopback stores sharing a cookie namespace. Local HTTP cannot establish production TLS cookie behavior. |
| DEV-GATE-001 | Default-disable live marketplace money, specialist claims, campaigns, loyalty and other consequential policies until trusted provider/policy evidence exists. `campaign.activation_approved` is an additional explicit implementation gate. | No legal, commission, currency, promotion funding or retention decision is inferred. All DEC-01..12 remain pending. |
| DEV-API-001 | Native WP REST error serialization and a bounded implemented JSON-schema subset are currently used. List cursors use UUID continuation; full scope-bound opaque cursor contract is unfinished. Public quota is currently IP-based, not the complete edge/session policy. | Full OpenAPI conformance, fair throttling and exhaustive schema/response verification remain IN_PROGRESS. |
| DEV-LIFECYCLE-001 | Only wishlist/comparison/history have entry-point lifecycle integration in the active slice. Other module changes fail501; descriptive module availability is explicitly partial. | Do not advertise a disabled state while live callbacks still accept work. Full dependency graph, migrations and financial obligation drain remain unfinished. |
| DEV-HPOS-001 | Initial native CRUD tests ran with HPOS disabled on both source sites. | Their evidence is legacy storage only. A supported sync/verify/enable and preservation check is required before claiming HPOS execution. Metadata declaration alone is insufficient. |
| DEV-STORE-001 | Preserve native WC pages; their synthetic fixture routes may be `/shop-2/`, `/cart-2/`, `/checkout-2/`. Resolve current WC page links instead of assuming slugs. | Seeder migrates only an unchanged owned hero default and preserves merchant edits. Local-only Woo coming-soon is explicitly disabled for anonymous browser testing. |
| DEV-SECRET-001 | A bootstrap exception originally printed an unused synthetic credential; it was rotated before installation and error output was fixed. A later login page-load race captured a local password in a failure context. | Sensitive failure artifact removed; all local administrator passwords rotated and sessions invalidated. Test waits for completed login loading and verifies username before submitting. No production credentials were used. Exact-value hygiene checks cannot establish absence of all possible secrets. |
| DEV-PACKAGE-001 | Deterministic ZIP timestamps/order and SHA256 manifests are used for development artifacts. WC/WP are declared dependencies, not bundled. | Reproducibility must be checked by two builds of frozen source. No signed update distribution, publication or verified release candidate is claimed. |
| DEV-AUDIT-001 | `npm audit --json` reached the official registry but its advisory request failed ECONNRESET. | Vulnerability audit BLOCKED, not PASS or zero findings. A later successful audit must replace this unresolved check. |

Native products/orders remain native. Generic extension entities do not replace WooCommerce order storage. Mapped marketplace products fail closed; no successful provider event, settlement, refund or sender is fabricated. Human financial, legal, domain, visual, accessibility and operational review remains separate from model review.
